# My Semester

개인 노트북에서 한 학기의 시간표, 수업계획, 체크리스트, 캘린더, 시험 정보와 주차별 메모를 관리하는 정적 웹사이트입니다. 학교명은 표시하지 않으며, 별도 서버나 유료 호스팅 없이 GitHub Pages에서 실행할 수 있습니다.

## 들어 있는 화면

- 전체 시간표와 과목별 교수·강의실 빠른 보기
- 9개 과목의 수업계획서 요약과 15주차 강의 내용
- 과목별/전체 체크리스트
- 주차별 계획, 과제, 시험, 직접 추가 일정을 모은 전체 캘린더
- 과목별 시험 일정·범위·기준 메모
- 매주 수업 메모와 복습 체크
- 채플 좌석 B구역 105번, A구역 132번
- 라이트/다크 모드, 모바일 레이아웃, JSON 백업·복원

모든 수정 내용은 현재 브라우저의 `localStorage`에 자동 저장됩니다. 브라우저 데이터 삭제나 다른 브라우저 사용 전에는 왼쪽 과목 메뉴의 **백업** 버튼으로 JSON 파일을 받아두는 것이 좋습니다. 기기 간 동기화는 하지 않습니다.

## 로컬에서 열기

별도 설치나 빌드가 없습니다. `index.html`을 직접 열어도 되지만, 브라우저 저장 동작을 안정적으로 유지하려면 이 폴더에서 간단한 로컬 서버를 실행하는 편이 좋습니다.

```powershell
python -m http.server 4173
```

그다음 `http://localhost:4173`을 엽니다.

## GitHub Pages에 올리기

1. 이 폴더를 GitHub 저장소의 `main` 브랜치에 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/ (root)`를 선택하고 저장합니다.

`index.html`, `style.css`, `data.js`, `app.js`만으로 동작하며 Render, 데이터베이스, 환경변수는 필요하지 않습니다.

## 날짜에 관한 메모

수업계획서에는 대부분 실제 날짜가 아니라 1~15주차만 적혀 있어, 캘린더 날짜는 2026년 9월 첫 수업 요일을 기준으로 연결했습니다. 공휴일, 보강, 학교의 실제 학사 일정에 따라 달라질 수 있으므로 캘린더나 과목의 **주차 정보 수정**에서 바로 고칠 수 있습니다.
